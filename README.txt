## My Projects

### 1. Hash Table Login System — C

For this university project, I worked on a login system using hash tables and linked lists.

**Skills:** C, data structures, algorithms, memory management and problem-solving.

### 2. YouTubeClicker — MIT App Inventor

I created a basic Android clicker game using MIT App Inventor.

Players earn one point each time they click a button. The game also includes a reset feature and a high-score system.

When the app is closed and reopened, the highest score remains saved, while the current score resets to zero.

**Skills:** MIT App Inventor, Android development, block-based programming, user interaction and data storage.

### 3. Estate Agent Property Management System — C#

This project helped me develop my understanding of software development and working with property-related information.

**Skills:** C#, .NET, JSON and problem-solving.
